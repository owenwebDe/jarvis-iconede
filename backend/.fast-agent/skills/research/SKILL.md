# RESEARCH AND SEARCH

## How to Search the Web:
Run the web search utility via shell execution:
```bash
python tools/web_search.py "<your search query>" --max 5
```

## Rules
- Always cite the source URL and title in your report.
- Synthesise information from multiple authoritative sources.
- For reading specific web pages, use python requests / httpx.
